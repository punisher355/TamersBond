# Chapter 4: Classes

Classes are the part of a Tamer's character that represents **how they grew**.

Crest Stats describe a Tamer's natural strengths. Skills describe what they know how to do. Classes are different: a class represents the habits, lessons, relationships, and turning points that shaped a Tamer over the course of their adventure.

Each season book contains its own classes, based on the Tamers and character arcs from that season. A class might be built around Courage, Friendship, Love, or another defining trait, but the rules for using classes are the same in every season.

---

## What Is a Class?

A class is a progression of abilities arranged into a small tree.

Every class contains:

- **A Core Class**, which establishes the class's theme and gives its first ability.
- **Tier 2**, which expands on the Core Class.
- **Tier 3**, which represents the class's strongest and most specialized abilities.

You do not need to complete the entire tree. A Tamer can stop after taking the Core Class, continue into one tier, or eventually invest heavily enough to reach Tier 3.

The complete class trees are found in the season books.

---

## Class Requirements

Every Core Class and class ability lists its requirements.

A requirement might include:

- A minimum Crest Stat rank.
- A specific class ability.
- A combination of both.
- A special game rule, such as having unlocked a particular Digivolution Stage.

You must meet **all** listed requirements before purchasing an ability.

If an ability does not list a requirement, there is no additional requirement beyond the normal class-tree rules.

---

## Taking a Core Class

A Core Class is the foundation of a class.

When you purchase a Core Class, you gain its ability immediately and become a member of that class.

Core Classes normally require a Crest Stat rank and cost between **200 and 300 EXP**, although a special Core Class may use a different requirement when its theme calls for it.

A Tamer may take the Core Class of any class they qualify for. You do not need to take classes in any particular order, and taking one class never prevents you from taking another.

---

## Moving Up the Class Tree

You cannot skip tiers.

To purchase an ability from **Tier 2**, you must already have the Core Class.

To purchase an ability from **Tier 3**, you must already have at least one ability from Tier 2.

You do **not** need to purchase every ability in a tier.

For example, a Tamer could take:

> Core Class → Tier 2 ability → stop

They could also take:

> Core Class → Tier 2 ability → Tier 2 ability → Tier 3 ability

The class tree is a path of access, not a checklist.

Some individual abilities may list additional prerequisites. When they do, those prerequisites must also be satisfied.

---

## Spending EXP on Classes

Classes use the same EXP pool as everything else in character advancement.

There is no separate Class EXP.

Whenever you earn EXP, you can spend it on:

- Increasing Crest Stats.
- Increasing Skills.
- Purchasing class abilities.

This means every class purchase is a real choice. Spending EXP on a class means having less EXP available for your other forms of advancement.

The EXP Cost listed beside an ability is the amount you must spend to purchase it.

Once purchased, a class ability is permanently part of your Tamer unless a rule specifically says otherwise.

---

## Having Multiple Classes

A Tamer can have **any number of classes**.

You do not have to finish one class before taking another. You can purchase a Core Class from one tree, return to it later, and eventually begin a completely different class.

This is intentional. Classes are meant to describe the individual Tamer, not force every character into a single predetermined build.

---

## Class Abilities and Actions

Class abilities use the terminology and action rules found elsewhere in this book.

When an ability says **Basic Action**, **Free Action**, **Reaction**, **attack roll**, **skill check**, or another defined game term, use the normal rules for that term.

If a class ability changes an existing rule, the class ability takes precedence for that specific situation.

Unless an ability specifically says otherwise, its effects apply only to the Tamer who purchased it and their partner Digimon.

---

## Building a Tamer Through Classes

There is no single correct way to build a Tamer.

A class should reward a player for leaning into the kind of person their Tamer is becoming. The strongest choices are not necessarily the ones with the biggest numbers; they are the choices that make the Tamer feel more like the character they are trying to portray.

A class might make a Tamer:

- Better at supporting their partner.
- More dangerous when their partner is pushed to the limit.
- Better at protecting other characters.
- More capable of solving problems outside combat.
- More effective at using Hope.
- Better at interacting with Digimon.
- Capable of actions that other Tamers simply cannot perform.

The exact abilities are different from season to season.

The framework stays the same.
